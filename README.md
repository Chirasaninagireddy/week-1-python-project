# Personal Information Manager

##  Project Overview
This is a beginner-level Python project that stores and displays personal information.  
The goal of this project is to practice basic programming concepts such as variables, input/output, loops, and condition handling.

## Setup Instructions

Follow these steps to run the project:

1. Install Python (if not installed)
2. Download or clone this repository:
https://github.com/Chirasaninagireddy/week-1-python-project.git

3. Navigate to the folder:
   cd week-1-python-project

4. Run the program:
   python main.py

## Code Structure

The project has a simple structure:

- `main.py` → Main Python program  
- `README.md` → Project documentation

##  Technical Details

This project uses:

- Variables to store data  
- `input()` function for user input  
- Conditional statements for validation  
- Arithmetic operations (age in months)  
- String formatting for output display  

## Testing Evidence

Test cases used:

1. **Valid Input Test**
   - Input: All fields filled correctly  
   - Output: Displays complete information  

2. **Empty Input Test**
   - Input: Empty value  
   - Output: Prompts user again  

3. **Edge Case**
   - Age = 0 or large number  
   - Output: Still calculates months correctly  

## Features

- Takes user input
